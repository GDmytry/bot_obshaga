# Smart-Общага 502 🏠

Единая экосистема управления комнатой: финансовый учет совместных расходов («Умный Общак»), интерактивные списки очередей и контроль дисциплины.

---

## 🛠 Технический стек и архитектура

Система построена по модульному асинхронному принципу:
- **Telegram Бот**: `aiogram 3.x` (поддержка HTTP и SOCKS5 прокси для обхода блокировок в РФ)
- **Веб-дашборд и Mini App**: `FastAPI` + `Uvicorn` + `Jinja2` (порт `8000`)
- **База данных**:
  - `PostgreSQL 15` (через `asyncpg` с connection pool) — основной режим (Production).
  - `SQLite` (через `aiosqlite` и `dev_sqlite.py`) — режим локальной разработки (`DEV_MODE=1`).
- **Обход блокировок (VPN / Прокси)**: контейнер `v2rayA` (веб-интерфейс на порту `2017`, локальный прокси на `20171` / `20170`).
- **Фоновые задачи**: `APScheduler` (автоснятие ограничений, еженедельные финансовые отчёты по понедельникам).
- **Метрики и мониторинг**: `Prometheus` (сбор метрик `/metrics` на порту `9090`) + `Grafana` (порт `3000`).

## 🤖 Команды Telegram-бота

### Для всех жильцов:
- `/start` или `/help` — Справка и главное меню
- `/register` — Регистрация жильца в системе
- `/status` — Список зарегистрированных жильцов и статус сети/VPN
- `/buy <сумма> <описание>` — Записать совместный расход в «Умный Общак» (делится поровну)
- `/balance` — Матрица взаимных долгов с автоматическим взаимозачётом
- `/q <название>` — Создать или открыть интерактивный список очереди (с кнопками)
- `/warns` — Просмотр активных предупреждений и статуса ограничений

### Для администраторов (указанных в `ADMIN_IDS`):
- `/warn @username причина` — Выдать выговор нарушителю (при 3 выговорах накладывается ограничение)
- `/unwarn @username` — Снять выговор и досрочно снять ограничения
- `/vpn_on` — Включить VPN
- `/vpn_off` — Выключить VPN

## 🚀 Установка на сервер (Armbian / Debian / Ubuntu)

### Шаг 1. Клонирование репозитория на сервере

Подключитесь к серверу по SSH и склонируйте проект:
```bash
git clone https://github.com/ВАШ_АККАУНТ/bot_obshaga.git
cd bot_obshaga
```

### Шаг 2. Автоматическая установка зависимостей

Запустите готовый установочный скрипт:
```bash
bash install.sh
```
Скрипт автоматически:
1. Установит `docker.io`, `docker-compose-plugin`, `git`.
2. Включит автозагрузку Docker.
3. Создаст файл `.env` из шаблона `.env.example`.
4. Выведет локальный IP-адрес вашего сервера в сети.

### Шаг 3. Заполнение настроек бота (`.env`)

Откройте файл конфигурации:
```bash
nano .env
```
Укажите:
- `BOT_TOKEN` — токен от `@BotFather`
- `ADMIN_IDS` — ваш Telegram ID (число)
- Сохраните файл (`Ctrl+O`, `Enter`, затем `Ctrl+X`).

### Шаг 4. Запуск контейнеров

```bash
docker compose up -d --build
```

### Шаг 5. Настройка обхода блокировок в РФ (через веб-интерфейс v2rayA)

Так как сервер находится в РФ, прямое подключение к Telegram API блокируется. В проект уже встроен контейнер `vpn-client` (v2rayA):

1. Откройте в браузере с компьютера:
   `http://<IP_СЕРВЕРА>:2017`
2. При первом входе введите любой логин и пароль администратора.
3. Нажмите **Import** и вставьте вашу ссылку / ключ (VLESS Reality, Shadowsocks, Trojan или подписку от вашего VPN).
4. Выберите узел, нажмите **Ready** и кнопку **Start** (вверху слева).
5. Бот автоматически подключится к Telegram через прокси `http://vpn-client:20171` (встроенный механизм переподключения сам подхватит соединение в течение 5 секунд).
